# Ganesh Gowda — Portfolio v2

An original, engineering-first personal portfolio built from scratch with React, TypeScript, Vite, Framer Motion and a custom visual system.

## Direction

The site combines cinematic motion, editorial typography, immersive project presentation and production-minded frontend architecture. It takes inspiration from the qualities we liked in existing portfolios without reproducing their layouts, branding or visual language.

## Stack

- React + TypeScript
- Vite
- Framer Motion
- Lucide React
- Custom CSS design system
- Responsive layouts
- Reduced-motion support

## Sections

- Hero / introduction
- Selected work
- About / engineering profile
- Engineering stack
- Contact

## Local development

```bash
npm install
npm run dev
```

Production validation:

```bash
npm run check
```

## Notes

Project links and profile details are kept in `src/data.ts` so content can be updated without touching the UI structure.
